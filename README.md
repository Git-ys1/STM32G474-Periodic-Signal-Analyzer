# STM32G474 周期信号测量分析装置

本仓库用于开发 2026 年全国大学生电子设计竞赛赛区赛（TI 杯）G 题“周期信号测量分析装置”。

装置以 STM32G474 为主控，面向 50 Ω 输入的周期信号，完成时域波形、峰峰值、真有效值、基频、正频率轴电压频谱及主要频谱分量幅值的测量与显示。正式题目还要求在不低于 1 MHz、200 mVpp 的单频干扰下完成被测信号分析。

## 两条独立开发线

### 串口屏显示

`projects/tjc_display_demo` 是显示负责人维护的独立 STM32CubeIDE 工程，使用 STM32G474 和淘晶驰 TJC8048X270_011R 七英寸串口屏，负责：

- 1 个或 3 个完整周期的时域波形显示；
- 峰峰值、真有效值和基频显示；
- 正频率轴频谱及主要分量显示；
- 淘晶驰页面、按钮、自定义串口协议和 `addt` 曲线传输。

### 信号处理

`projects/teammate_adc_reference` 是信号处理负责人维护的独立 STM32CubeMX/Keil 工程，包含 ADC、DAC、DMA、定时器、串口和 AD9833 等代码。

两套工程当前独立开发、独立验证。本仓库只是统一保存实际工程代码，不能把其中一套误认为另一套的子模块，也不代表已经完成整机集成。

## 赛题关键约束

- 输入接口：50 Ω，BNC；
- 被测信号频率：10 kHz 至 500 kHz；
- 被测信号峰峰值：50 mV 至 250 mV；
- 频率分辨率：500 Hz；
- 峰峰值、真有效值及频谱分量幅值绝对误差不大于 5 mV；
- 基频绝对误差不大于 1 kHz；
- 按键选择稳定显示 1 个或 3 个完整周期；
- 单项启动后 2 秒内完成；
- 抑制不低于 1 MHz、200 mVpp 的单频干扰；
- 单路 5 V 直流稳压供电；
- 显示屏尺寸不小于 6 英寸。

赛题 PDF、赛区问答、器件资料和阶段性报告保存在独立资料目录中，不纳入本代码仓库。
