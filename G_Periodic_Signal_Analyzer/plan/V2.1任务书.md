## 三、当前算法基线

现有流程为：

```text
2048个ADC码值
→ 去均值并换算mV
→ 根据折叠频率计算每个样本相位
→ 向相邻两个相位槽线性分权
→ 每槽普通加权平均
→ 环形线性补齐空槽
→ 去除波形均值
→ 256点线性插值到794点
```

现有问题：

- 一个异常ADC样本会污染相位槽；
- 256→794插值不会制造毛刺，但会把坏槽扩展到约3个屏幕像素；
- 相位覆盖极差或折叠频率错误时，Huber也不能创造不存在的信息。

## 五、两遍Huber算法

### 5.1 第一遍：普通折叠

调用现有函数得到初始周期波形：

```python
initial_waveform, _, phases = phase_fold_waveform(...)
```

### 5.2 计算每个ADC样本的预测值

根据样本相位，从初始256点周期波形中做周期线性插值：

```text
phase
→ position=phase×bin_count
→ 读取相邻两个槽
→ 线性插值得到predicted_mv
```

### 5.3 计算残差与鲁棒尺度

```python
residual = centered_sample_mv - predicted_mv
residual_center = np.median(residual)
absolute_deviation = np.abs(residual - residual_center)
mad = np.median(absolute_deviation)
robust_sigma = 1.4826 * mad
```

Huber阈值：

```python
adc_lsb_mv = volts_per_code * 1000.0
delta_mv = max(
    huber_k * robust_sigma,
    minimum_delta_lsb * adc_lsb_mv,
)
```

不能直接固定成几mV，否则换量程或噪声变化后失效。

### 5.4 计算Huber权重

\[
w_n=
\begin{cases}
1,&|r_n|\le\delta\\
\delta/|r_n|,&|r_n|>\delta
\end{cases}
\]

代码形式：

```python
sample_weights = np.ones_like(residual)
centered_residual = residual - residual_center
large = np.abs(centered_residual) > delta_mv
sample_weights[large] = (
    delta_mv /
    np.abs(centered_residual[large])
)
```

### 5.5 第二遍：重新折叠

把Huber权重乘入原来的左右分配权重：

```python
left_weight = (1.0 - fraction) * sample_weights
right_weight = fraction * sample_weights
```

再完成：

```text
加权累加
→ 加权平均
→ 环形补齐空槽
→ 去除波形均值
```

注意：

- 第二遍仍折叠原始中心化ADC样本；
- 不能把第一遍预测波形当作第二遍输入；
- 不得做全局滑动平均；
- 不得引入三次样条。

### 7.1 干净数据回归

### 7.2 人工孤立毛刺

在生成的ADC码值中确定性注入以下异常：

| 类型 | 数量 | 幅度 |
|---|---:|---:|
| 轻微孤立毛刺 | 4个 | ±20mV |
| 中等孤立毛刺 | 16个 | ±40mV |
| 严重孤立毛刺 | 32个 | ±80mV |
| 连续突发异常 | 连续8点 | ±40mV |

要求：

- 使用固定随机种子；
- 正负毛刺均包含；
- mV换算为ADC码后四舍五入；
- 限制到0～4095；
- 每次运行结果必须一致。

连续8点异常用于暴露算法边界，不要求Huber一定完全消除。

### 7.3 两种频率条件

每组污染数据都分别测试：

1. 使用干净数据得到的折叠频率，只研究相位折叠抗毛刺能力；
2. 使用污染数据重新执行频率细化，评估完整链路。

这样可以区分：

```text
Huber折叠失败
```

和：

```text
异常点先破坏了频率估计，导致后续全部折叠错误
```
