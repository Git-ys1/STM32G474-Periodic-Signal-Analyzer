4. HMI协议修改
4.1 页面初始化帧

新的页面初始化帧为6字节：

A5 20 01 time_id spec_id 5A

对应HMI后初始化事件：

printh A5 20 01
prints s_time.id,1
prints s_spec.id,1
printh 5A
4.2 按钮帧

保持：

A5 01 01 5A：显示1周期
A5 01 03 5A：显示3周期
4.3 MCU解析要求

tjc_hmi.c必须同时识别：

6字节页面初始化帧；
4字节按钮帧；
FE FF FF FF透传就绪；
FD FF FF FF透传完成；
淘晶驰错误返回帧。

建议事件结构改为：

typedef enum
{
    TJC_EVENT_NONE = 0,
    TJC_EVENT_DASHBOARD_READY,
    TJC_EVENT_SHOW_ONE_PERIOD,
    TJC_EVENT_SHOW_THREE_PERIODS
} TJC_Event;

增加页面配置：

typedef struct
{
    uint8_t time_curve_id;
    uint8_t spectrum_curve_id;
    bool valid;
} TJC_DashboardInfo;

收到页面初始化帧后：

dashboard.time_curve_id = frame[3];
dashboard.spectrum_curve_id = frame[4];
dashboard.valid = true;

严禁再次写死：

#define TIME_CURVE_ID 11U
#define SPECTRUM_CURVE_ID 1U

在display.c中修改：

#define DISPLAY_CURVE_Y_MAX       144U

#define DISPLAY_TIME_MARGIN       5U
#define DISPLAY_SPEC_MARGIN       3U

曲线发送缓冲区：

页面初始化完成后，按顺序执行：

1. 保存s_time和s_spec真实ID
2. 绘制当前周期模式的时域波形
3. 绘制频谱

    dashboard.time_curve_id,

8. 六个文本控件的更新函数

在display.c中建立统一函数：

/**
 * @brief 更新单页面中的全部测量参数文本。
 *
 * 每次都向txt属性写入完整字符串，包含名称、数值和单位。
 * 不允许只写数字，否则会覆盖HMI中原有的前缀和单位。
 */
static void Display_UpdateResultTexts(
    float vpp_mv,
    float rms_mv,
    float fundamental_hz,
    const SpectrumPeak *peaks,
    uint8_t peak_count);

8.7 编码要求

由于t_c1～t_c3包含中文：

二者必须一致，否则可能乱码或不显示。官方特别强调单片机发送的字符串编码需要与屏幕工程编码一致。

10. 初始化流程

Display_Init()中：

1. 初始化TJC串口模块
2. 生成模拟时域和频谱数据
3. 等待屏幕启动
4. 发送 page dashboard
5. 不立即发送曲线
6. 等待A5 20 01 time_id spec_id 5A
7. 收到页面就绪帧后再绘制两个曲线并更新文本

页面后初始化是在页面刷新完成后执行，因此收到该帧后再传输曲线更安全。

12. 验收测试
上电

串口应收到：

A5 20 01 <time_id> <spec_id> 5A

随后两次曲线传输均应出现：

FE FF FF FF
FD FF FF FF

一次对应s_time，一次对应s_spec。

文本

必须同时显示：

Upp: 200.0 mV
Urms: 70.71 mV
f1: 100.0 kHz
基波: 100.0 kHz / 100.0 mVpk
谐波1: --.- kHz / --.- mVpk
谐波2: --.- kHz / --.- mVpk
1T按钮

收到：

A5 01 01 5A

仅刷新s_time，显示一个完整周期。

3T按钮

收到：

A5 01 03 5A

仅刷新s_time，显示三个完整周期。

禁止出现
12 FF FF FF
1A FF FF FF
1C FF FF FF
24 FF FF FF

其中：

0x12通常说明曲线ID或通道错误；
0x1A说明控件/变量名称无效；
0x1C常见于文本赋值语法错误，例如字符串未加双引号；
0x24表示串口缓冲区溢出。官方文本赋值要求内容必须包含双引号，并在指令末尾追加三个0xFF。
