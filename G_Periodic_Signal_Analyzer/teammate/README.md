# 队友代码区

本目录只保存队友原始工程，不在这里叠加显示代码。

| 路径 | 内容 | 规则 |
|---|---|---|
| [`current/`](current/README.md) | 2026-08-01 `win`双ADC、相位差与公式Vpp最新快照 | 只读对照 |
| [`archive/`](archive/README.md) | 更早的队友工程快照 | 禁止继续开发 |
| [`source_packages/`](source_packages/README.md) | 队友发来的原始压缩包 | 原样保存 |

队友下一版到达时：原始包存入`source_packages/`或先保留原始目录，旧版本移入
`archive/`，再将新源码提升为`current/`并以它为底座更新根目录`firmware/`。
