# 队友代码区

本目录只保存队友原始工程，不在这里叠加显示代码。

| 路径 | 内容 | 规则 |
|---|---|---|
| [`current/`](current/README.md) | 2026-08-01 `4096-2`双ADC、4096点、2.048 MS/s最新快照 | 只读对照 |
| [`archive/`](archive/README.md) | 更早的队友工程快照 | 禁止继续开发 |
| [`source_packages/`](source_packages/README.md) | 队友发来的原始压缩包 | 原样保存 |

队友下一版到达时：原样存入`source_packages/`，旧`current/`先移入
`archive/`，再以新工程为底座更新根目录`firmware/`。
