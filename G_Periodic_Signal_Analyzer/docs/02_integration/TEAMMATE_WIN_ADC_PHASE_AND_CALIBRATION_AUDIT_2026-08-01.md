# 队友 win 版 ADC、相位与标定审计

> 审计对象：`teammate/current`（原 `teammate/win`）
>
> 正式融合工程：`firmware`
> 结论口径：只把已在代码中闭环的内容视为“已实现”，测量表和拟合函数尚未给出时不把它们写成既成能力。

## 1. 结论

队友的新方法已经补齐了“从各频率分量中提取相位”的入口，理论上可以直接用幅值和相对相位重建稀疏谐波波形，并由重建曲线计算 `Upp`。因此它可作为显示复原的主路径。

但当前原始代码还不能单独取代相位同步折叠，原因如下：

1. `bw9_phase(f)`仍固定返回 0，模拟前端的频率相关相移没有标定。
2. 原始`getup()`的二分量分支把两项写成同频率，三分量分支又把 Hz 直接代入4096点相位网格，均会导致错误波形。
3. 当前频率仍以约500 Hz/bin的FFT峰值为主，离散频率偏差会传递到Goertzel相位。
4. 双ADC通道的增益、偏置和采样时差尚未分别标定，交错失配会形成奇偶点纹波和镜像。
5. 解析模型只覆盖已检出的2或3个分量，未建模分量、削顶和瞬态可能被隐藏。

正式固件已经修正解析合成公式，并停用运行时`Vpp_Robust()`；相位折叠/Huber仍保留为原始数据证据、残差校验和失配时回退路径。

## 2. 当前数据与算法链

```text
TIM3 CH4上升沿/下降沿
→ ADC1、ADC2各DMA采2048点
→ 按时间顺序交错为VO[4096]
→ 4096点FFT搜索2或3个分量
→ 9-bin RSS求每个分量幅值
→ Goertzel求对应分量相位
→ 前端幅相校正
→ 消除时间原点后的相对谐波相位
→ 4096相位点解析合成
→ max-min得到Upp，谱分量平方和得到Urms
→ 显示桥接与淘晶驰屏
```

交错序列为：

```c
VO[2 * i]     = adc_b[i]  * 3.3f / 4096.0f;
VO[2 * i + 1] = adc_b1[i] * 3.3f / 4096.0f;
```

这要求PA0、PA1接收同一信号，并保证ADC1是较早时刻、ADC2是较晚时刻。若物理接线、触发边沿或DMA数组含义不一致，后续相位模型会整体失真。

## 3. 幅值校正现状

队友代码先按FFT bin除以经验增益，再在峰值中心前后各4个bin内做幅值平方和：

\[
A_k=\frac{2}{N}\sqrt{\sum_{r=-4}^{4}|X[k+r]|^2},\qquad N=4096
\]

当前11档经验增益如下。按代码使用的500 Hz/bin近似换算，区间右端不包含：

| bin区间 | 近似频率区间 | 除数 |
|---:|---:|---:|
| 0～299 | 0～149.5 kHz | 5.92 |
| 300～419 | 150～209.5 kHz | 6.10 |
| 420～519 | 210～259.5 kHz | 6.19 |
| 520～559 | 260～279.5 kHz | 6.25 |
| 560～599 | 280～299.5 kHz | 6.32 |
| 600～679 | 300～339.5 kHz | 6.43 |
| 680～719 | 340～359.5 kHz | 6.62 |
| 720～799 | 360～399.5 kHz | 6.71 |
| 800～839 | 400～419.5 kHz | 6.83 |
| 840～879 | 420～439.5 kHz | 6.92 |
| 880以上 | 440 kHz以上 | 7.16 |

风险：该表以bin而不是Hz索引，采样率变化后边界随之漂移；阶梯边界还会使相邻频率的幅值不连续。正式标定应使用频率坐标和插值。

## 4. 相位推导与波形复原

设输入信号为

\[
x(t)=U_0+\sum_{m=1}^{M}A_m\sin(2\pi m f_1t+\varphi_m).
\]

模拟前端复频响记为

\[
H(f)=G(f)e^{j\theta_H(f)}.
\]

Goertzel测得第`m`个分量相位`\Phi_m^{meas}`后，先扣除前端相位：

\[
\Phi_m=\Phi_m^{meas}-\theta_H(mf_1).
\]

消除任意采样起点带来的公共时间平移，并补偿当前Goertzel正弦相位约定，可得到相对谐波相位：

\[
\psi_m=\operatorname{wrap}\left[\Phi_m-m\Phi_1-(m-1)\frac{\pi}{2}\right].
\]

随后只需在一个归一化相位周期内合成：

\[
u(\theta)=A_1\sin\theta+\sum_{m=2}^{M}A_m\sin(m\theta+\psi_m),\quad 0\le\theta<2\pi.
\]

最终

\[
U_{pp}=\max_{\theta}u(\theta)-\min_{\theta}u(\theta),\qquad
U_{rms}=\sqrt{\frac{1}{2}\sum_{m=1}^{M}A_m^2}.
\]

正式固件用4096个相位点计算`Upp`。离线72组双/三分量回归中，修正模型相对高密度真值的最大误差为0.037693 mV；原始`getup()`最大误差为237.181502 mV。该测试验证的是数学实现，不等价于验证实物前端标定。

## 5. 我们的相位折叠还要不要

要保留，但角色发生变化：

| 路径 | 主要作用 | 优点 | 失效条件 |
|---|---|---|---|
| 队友幅相模型 | 主显示、解析`Upp` | 平滑、点数固定、算力可控 | 幅相标定错、频率错、谐波漏检 |
| 相位折叠+Huber | 原始证据、残差校验、回退 | 不要求信号恰好只有2/3项 | 周期估计错、相位覆盖不足 |

建议质量门控：只有同时满足谐波整数关系、分量SNR、标定频率范围和“解析曲线对折叠数据的残差阈值”时，才显示解析模型；否则自动显示Huber折叠结果并标记低置信度。现阶段不应删除折叠路径。

## 6. 前端频扫与拟合建议

不要只拟合“增益”，应一次测得复频响：

\[
H(f_i)=G(f_i)e^{j\theta_i}.
\]

每个标定点至少记录：输入频率、信号源幅值/相位参考、ADC1与ADC2复数系数、温度、VDDA、量程和模拟通道配置。相位需先展开，再插值。

推荐流程：

1. 先以10 kHz粗扫全带宽；在截止区、增益/相位曲率变大区改为2～5 kHz。
2. 对`20log10 G(f)`和展开相位分别做分段线性插值。首版不使用高阶全局多项式，避免端点振荡。
3. 用未参与拟合的中点做验证；若幅值残差或相位残差超阈值，则在该区间自动加点。
4. 固件表项保存`frequency_hz/gain/phase_rad`，按Hz二分查找后插值，不再按FFT bin分档。
5. ADC1、ADC2分别建立`H_1(f)`、`H_2(f)`；必要时按噪声权重做复数融合：

\[
\hat C(f)=\frac{w_1C_1/H_1+w_2C_2/H_2}{w_1+w_2}.
\]

6. 用实物信号源、示波器参考、两路原始ADC数组和屏幕结果做同一时刻闭环验证，不能仅根据仿真或单张屏幕截图判定精度。

## 7. 本轮正式固件处理

- 保留队友双ADC、FFT、9-bin RSS、Goertzel和谱RMS主链。
- 修复解析波形按谐波阶数合成，避免Hz直接进入相位网格。
- 保留`Frontend_PhaseRad()`标定入口，当前返回0并明确标为待实测。
- 停用`Vpp_Robust()`运行调用；源码仅作为废弃历史留存，链接器不再分配其4096点排序缓冲。
- 保留显示桥接的相位折叠/Huber链，用于验证和回退。
- 本轮没有虚构增益或相位参数；11档幅值表仍是队友当前实验值。

## 8. 下一步最小闭环

1. 导出一组完整频扫原始表，不先拟合。
2. 统一FFT、Goertzel、报告中的有效采样率口径。
3. 增加亚bin频率细化或同步长度选择，减少离散频率引起的相位偏差。
4. 标定双ADC偏置、增益和时间偏斜。
5. 以解析模型对Huber折叠的残差建立质量门控。
6. 标定通过后，再决定是否精简折叠路径；在此之前不删除。
