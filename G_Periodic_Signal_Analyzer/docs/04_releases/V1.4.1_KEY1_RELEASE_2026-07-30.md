# V1.4.1 实体按键兼容版发布说明

日期：2026-07-30

基线：`v1.4.0`

适用工程：`firmware`

## 发布结论

V1.4.1在V1.4全量融合稳定基线上，为不可触摸的淘晶驰X2系列7英寸屏增加
板载KEY1控制。用户已完成实物验收，按键与原HMI按钮可以稳定共存。

## 硬件与动作

```text
KEY1 = PB8 / BOOT0
松开低电平，按下高电平
EXTI9_5上升沿中断
```

| 操作 | 结果 |
|---|---|
| 短按30～999 ms | 复用原1T/3T按钮命令并在两者间切换 |
| 长按至少1000 ms后松开 | 复用原测试按钮命令 |

按键功能由`BOARD_KEY_CONTROL_ENABLE`控制，设为`0U`即可关闭。

## 最重要的实现决策

实体键没有直接调用另一套绘图或刷新函数。HMI按钮帧和KEY1都进入：

```c
Display_ProcessButtonCommand()
```

因此：

- 1T、3T和测试的状态变化只有一个实现；
- HMI触摸/模拟器按钮与实体键不会产生两套语义；
- 原有`Display_Task()`、AnalyzerBridge和FE/FD通信链保持不变；
- 后续恢复触摸屏时不需要删除实体键支持。

## 中断边界

`HAL_GPIO_EXTI_Callback()`只记录按下时刻。`BoardKey_Task()`在主循环检测松开并
判定短按/长按，再向原按钮命令处理入口提交动作。

中断中禁止：

- 等待松开；
- 执行`cle/addt`；
- 阻塞式UART发送；
- FFT或波形重采样。

## 启动注意事项

PB8同时是BOOT0。不要在上电或复位时持续按住KEY1，避免BOOT0被采样为高电平而
影响正常从Flash启动。
