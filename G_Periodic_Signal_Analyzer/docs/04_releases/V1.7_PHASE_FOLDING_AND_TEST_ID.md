# V1.7 相位折叠、等效采样边界与测试编号

## 1. 本轮目的

本轮没有改变队友的ADC、FFT、Vpp、RMS和谱峰算法，只改进显示侧波形提取的可解释性与测试可观测性：

1. 说明当前“2048点相位折叠”如何从连续ADC数据得到一个周期；
2. 区分软件相位折叠与硬件顺序等效时间采样；
3. 给9组原生ADC测试加入固定编号`T1`～`T9`；
4. 生成理想波形与折叠波形的9组叠加对比图；
5. 保持真实ADC模式、显示协议和FE/FD握手不变。

## 2. 相位折叠是什么

“相位折叠”不是STM32或DSP库中的固定函数名。本项目用它描述：

> 已知周期信号的基频后，把连续采到的多个周期按“周期内相位”重新归类、平均，折叠成一个高密度周期。

常见相近名称包括：

- multi-cycle phase folding；
- phase binning；
- phase-domain averaging；
- coherent folding。

当前采样率为`Fs=1.024 MSPS`，缓冲区为2048点，采集时长为：

```text
2048 / 1.024 MHz = 2 ms
```

以250 kHz附近的基波为例，一个周期只有约4.1个原始采样点，但2 ms缓冲区包含约500个周期。若信号频率与采样时钟不是严格整数关系，各周期的采样位置会在周期内逐渐移动，因此全部2048点合起来能覆盖大量不同相位。

## 3. 当前算法

先对ADC码求均值并换算成去直流后的毫伏值`x[n]`。设折叠频率为`f_ref`，第`n`个样点在基波周期内的归一化相位为：

```text
phi[n] = frac(n * f_ref / Fs),  0 <= phi[n] < 1
```

将一个周期划分为`M=256`个相位槽：

```text
p = phi[n] * M
k = floor(p)
alpha = p - k
```

为了避免硬分箱造成跳变，一个样点按距离线性分配给相邻两个槽：

```text
sum[k]       += x[n] * (1 - alpha)
weight[k]    += 1 - alpha

sum[k + 1]   += x[n] * alpha
weight[k + 1]+= alpha
```

其中`k+1`在末尾环回到0。最后：

```text
wave[k] = sum[k] / weight[k]
```

未获得样点的槽使用环形线性插值补齐，再去除一次微小残余均值，得到一个周期的256点波形。显示层只负责把这256点插值为794列，并按1T或3T铺满屏幕。

## 4. 为什么折叠前还要细化频率

队友FFT输出的基频分辨率为500 Hz，报告值最多可能与真实频率相差250 Hz。相位误差会随采集时间累积：

```text
累计周期误差 = 频率误差 * 采集时长
```

例如：

```text
250 Hz * 2 ms = 0.5周期
```

若直接用这个频率折叠，缓冲区后半段可能与前半段相差半个周期，平均后会互相抵消。

因此桥接层只为“绘图”进行一次内部频率细化：

1. 以队友报告频率为中心搜索±500 Hz；
2. 步长10 Hz做正余弦相关；
3. 优先使用“幅度×谐波次数”最大的有效谱线提高相位灵敏度；
4. 对最佳点做三点抛物线插值。

细化结果只用于相位折叠，不回写队友对外显示的500 Hz分辨率测量值。

## 5. 与顺序等效时间采样的区别

队友建议的“每隔一个周期，把采样时刻向后移动一点”是正确的顺序等效时间采样思路。第`m`个周期的采样时刻可写为：

```text
t[m] = m*T + m*delta_t
```

对周期取模后，采样相位每次前进`delta_t`，等效时间间隔为`delta_t`，等效采样率为`1/delta_t`。

但它需要：

- 被测波形严格重复；
- 每周期有稳定触发；
- 周期测量和延时控制的抖动远小于`delta_t`；
- 采样触发链能够按计划改变延时。

当前工程是TIM3固定触发ADC、DMA连续采2048点，没有独立模拟触发、相位锁定或可控亚周期延时。因此现在不宜临时改成真正的顺序等效采样。

当前方法更接近“连续采样后的异步等效时间重排”：硬件仍按1.024 MSPS连续采样，软件根据相位把多个周期重新排序。二者目标相近，但当前方法不声称提升ADC奈奎斯特频率，也不能替代模拟带宽和抗混叠设计。

## 6. 是否需要显示模块再做图像复原

需要，但边界如下：

```text
队友：
ADC采样 + FFT + Vpp + RMS + 谱峰识别

AnalyzerBridge：
ADC去偏置 + 绘图频率细化 + 2048点相位折叠

Display：
256点周期快照 → 794列1T/3T + 频谱线 + 文本
```

因此“图像复原”已由`AnalyzerBridge_BuildRealWaveform()`完成，屏幕模块不需要再做FFT逆变换。正式时域图来自真实ADC样点的相位重排，不是仅凭谱峰幅值合成出来的假波形。

## 7. 测试编号

9组测试按生成顺序固定为：

| 编号 | 场景 |
|---|---|
| T1～T3 | 第1问低端、官方典型、高端 |
| T4～T6 | 第2问低端、中间、高端 |
| T7～T9 | 第3问低端、中间、高端 |

测试模式下，“谐波2”文本末尾追加`[Tn]`。真实ADC模式的编号为0，不显示后缀。编号只用于辨认测试向量，不参与任何计算。
