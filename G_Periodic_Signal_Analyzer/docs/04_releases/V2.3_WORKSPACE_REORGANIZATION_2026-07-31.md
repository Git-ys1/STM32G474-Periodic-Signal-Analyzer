# V2.3 工作区结构整理

日期：2026-07-31
状态：已发布为`v2.3.0`

本版本同时收录此前尚未单独发布的V2.2定版成果：两遍Huber后投影到FFT已识别
整数谐波、上电默认增强Huber、本地KEY1长按测试，以及保持长按刷新和关闭随机
测试的队友生产融合包。

## 目标

让用户、队友和下一位Codex一眼找到唯一主线，消除`projects/`中多个工程并列、
`docs/`平铺和空缓存目录造成的歧义。

## 路径迁移

| 原路径 | V2.3路径 | 定位 |
|---|---|---|
| `projects/g474_full_integration_test` | `firmware/` | 唯一主线 |
| `projects/teammate_adc_reallynewest!` | `teammate/current/` | 当前队友快照 |
| `projects/teammate_adc_newest` | `teammate/archive/adc_newest/` | 历史快照 |

| `projects/*.zip` | `teammate/source_packages/` | 原始收件包 |
| `docs/*.md` | `docs/00_...`至`docs/99_...` | 按用途分层 |

`projects/`、Python缓存、旧Keil日志和废弃demo的可重建`Debug/`输出已清理；
原本为空的`tmp/`曾移除，随后被并行数学说明任务重新建立，现已明确标为临时、
默认不提交。真实ADC XLSX、队友原始ZIP、V2.2交付包和全部源码均保留。
