# V2.5双ADC 4096点VO浮点桥接

发布日期：2026-08-01

## 定版结论

| 项目 | V2.5口径 |
|---|---|
| 队友底座 | `teammate/current`，来源`4096-2` |
| ADC | ADC1/PA0上升沿 + ADC2/PA1下降沿 |
| 帧长 | 两路各2048点，交错为`VO[4096]` |
| 等效采样率 | 约2.048193 MS/s |
| FFT | 4096点，约500 Hz/bin |
| 桥接输入 | 队友已换算好的浮点电压`VO[4096]` |
| 显示 | 512点时域、256点频谱、动态坐标与独立Mpp |

## 接口调整

旧桥接接口读取`adc_b`并自行执行ADC码值换算。双ADC后`adc_b`只有2048点，
却曾以4096点长度传入，存在越界；重复换算还会使上游和显示端的电压口径分裂。

V2.5改为两阶段接口：

```c
AnalyzerBridge_PrepareReal(
    VO,
    ADC_SIZE,
    ANALYZER_SAMPLE_RATE_HZ,
    spectrum_flag,
    spectrum_frequencies_hz,
    spectrum_amplitudes_v
);

float Vrms = Vpp_R();
AnalyzerBridge_PublishPreparedReal(vpp, Vrms);
```

`PrepareReal()`必须位于`Vpp_R()`之前，因为队友当前`Vpp_R()`会原地去直流并
清零`VO`尾部。桥接层同步消费完整VO，随后再原子提交Vpp和RMS；显示层不会
看到半成品。

## 与4096-2的关系

- 已合入队友把频响修正提前到FFT幅值数组的最新版逻辑；
- 队友`Vpp_Robust()`、`Vpp_R()`、ADC、DMA和TIM3算法未被我方重写；
- 本地实物屏KEY1短按切换1T/3T、长按测试；
- 发给队友的生产包不含`main.c`，测试宏关闭，KEY1长按继续刷新。
