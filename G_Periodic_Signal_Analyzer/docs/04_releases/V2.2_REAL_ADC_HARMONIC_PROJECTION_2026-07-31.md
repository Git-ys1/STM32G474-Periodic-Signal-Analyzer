## 2. PC端MCU等价重放

`tools/analyze_real_adc_smoothing.py`重放以下链路：

```text
2048点uint16 ADC
→ 当前队友FFT峰值选择
→ ±500 Hz相关搜索细化折叠频率
→ 256槽普通或两遍Huber相位折叠
→ 候选平滑算法
→ 当前上升过零触发
→ 794点周期线性插值
→ 145像素纵向量化
```

同时在原始2048点上独立执行Huber迭代加权谐波拟合，作为不依赖256槽折叠
结果的参考曲线；再把样本按索引模4拆成四组，检查不同子样本拟合是否一致。
三组最大两两RMSE为1.840、1.133、2.079 mV，说明参考曲线稳定。

当前FFT输出能够从三组实测ADC分别推导出`{1,8}`、`{1,3,4}`和
`{1,2,7}`。A组8次谐波会命中相邻两个FFT峰，固件按整数次数去重。

## 3. 候选算法比较

比较了普通折叠、Huber折叠、Huber后周期Savitzky-Golay 9/15/21点平滑，
以及Huber后已识别谐波投影。Savitzky-Golay可以降低局部抖动，但窗口越大越
容易削弱真实高次谐波峰值，且仍保留额外折返点。

选定算法为：

```text
两遍Huber相位折叠
→ 从FFT频率/基频推导合法整数谐波次数
→ 256点波形正交投影到这些正弦/余弦基
→ 删除不属于已识别信号模型的相位槽抖动
```

对长度为 \(N=256\) 的Huber波形 \(y[n]\)，每个已识别谐波次数 \(h\) 的
系数为：

\[
a_h=\frac{2}{N}\sum_{n=0}^{N-1}y[n]\cos\left(\frac{2\pi hn}{N}\right)
\]

\[
b_h=\frac{2}{N}\sum_{n=0}^{N-1}y[n]\sin\left(\frac{2\pi hn}{N}\right)
\]

重建曲线为：

\[
\hat y[n]=\sum_{h\in H}
\left[
a_h\cos\left(\frac{2\pi hn}{N}\right)
+b_h\sin\left(\frac{2\pi hn}{N}\right)
\right]
\]

这不是移动平均，也不是用显示比例掩盖误差；它保留FFT已识别基波和谐波的
相位与幅值系数，只删除题目信号模型之外的波动。

## 5. 固件实现与开关语义

`AnalyzerBridge_ApplySelectedHarmonicProjection()`已加入
`Core/Src/analyzer_bridge.c`。实现特点：

- 基波次数1始终保留；
- 其余FFT谱线只有在`频率/基频`与最近整数相差不超过0.15时才保留；
- 谐波次数限制在1～127并去重；
- 每个次数只调用一次`cosf()`和`sinf()`，256点循环使用振荡器递推；
- 复用既有`s_phase_sum_mv[256]`，不增加千字节级静态RAM；
- 只在折叠模式1中执行，不修改队友`Upp`、`Urms`、基频和频谱结果。

HMI协议没有改变：

```text
A5 02 08 00 5A：普通相位折叠
A5 02 08 01 5A：Huber + 已识别谐波投影
```

定版后上电默认改为增强Huber，适配现场不可触摸屏。界面原有
`普通/Huber`文字可以继续使用，但V2.2中的“Huber”侧已经包含投影步骤。

## 7. 实机验收重点与边界

当前板上已经是本轮固件。请在同一稳定信号下快速切换普通与Huber侧，优先观察
原本单调斜坡上的额外小峰谷是否消失，同时确认六项文本和频谱不随开关改变。

该算法依赖上游FFT正确识别题目允许的分量。如果FFT漏掉真实谐波或把噪声误判为
合法整数谐波，投影会相应漏保留或误保留成分；因此仍需同步保留信号源、PA0
示波器、`adc_b[2048]`和屏幕结果。它解决的是显示波形中“模型外抖动”，不能
替代VDDA/Vpp标定、频谱伪峰审计或低相位覆盖可信度判断。

用户完成实屏观察后已确认该平滑版本定版。最终本地验证配置构建为
`Code=69652, RO=59000, RW=52, ZI=63060`，HEX长度362077字节，SHA-256为
`C4F6BADEAB9B45F0CFB7C5F50FF58912CC9A4C2C64259FA14DBC5991C9A2DCCB`；
该最终默认Huber HEX尚未再次烧录。队友生产配置关闭随机测试后也已通过
`0 Error(s), 0 Warning(s)`构建。
