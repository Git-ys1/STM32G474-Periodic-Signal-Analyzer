# V2.4.0 紧凑坐标轴与独立模型Mpp

发布日期：2026-07-31
基线：`v2.3.0`
唯一固件：`firmware/`

## 发布内容

| 项目 | V2.4.0结果 |
|---|---|
| 时域曲线 | 512×256，发送512字节 |
| 频谱曲线 | 256×256，发送256字节，0～500 kHz占满全宽 |
| 时域Y轴 | 使用独立`Mpp/2`到`-Mpp/2`的实际mV数值 |
| 时域X轴 | 5个虚拟浮点刻度，按基频和1T/3T实时计算us |
| 频谱Y轴 | 按队友FFT分量最大幅度的1.15倍显示5档实际mV数值 |
| 频谱X轴 | HMI固定0、100、200、300、400、500 kHz |
| 周期开关 | `sw_period`继续发送原1T/3T帧，MCU主循环回写视觉状态 |
| 独立幅值 | 新增全部2048点Huber谐波模型`Mpp`，不替换队友`Upp` |

## HMI契约

曲线位置：

```text
s_time: x=16,  y=17, w=512, h=256
s_spec: x=544, y=17, w=256, h=256
```

动态控件：

```text
n_ty4 n_ty3 n_ty2 n_ty1 n_ty0
n_sy4 n_sy3 n_sy2 n_sy1 n_sy0
x_tx0 x_tx1 x_tx2 x_tx3 x_tx4
sw_period t_vpp2
```

纵轴是普通文本控件，初值`---`、透明背景、`txt_maxl=10`；时域横轴是虚拟
浮点控件，`vvs0=0`、`vvs1=1`。坐标控件均可保持局部作用域。页面后初始化
仍只发送曲线ID、触发方式和Huber状态三帧，不增加周期帧。

完整属性和坐标见
[512/256紧凑布局定稿](../01_architecture/HMI_COMPACT_LAYOUT_DRAFT.md)。

## 实现边界

- 未修改`firmware/Core/Src/main.c`中的队友FFT、`Vpp_Robust()`、RMS或采集；
- `Mpp`是独立对照值，后续可启用、替换或停用，不与队友`Upp`互相覆盖；
- 真实时域波形显示前按同一个`ANALYZER_FRONTEND_VOLTAGE_GAIN=6.0f`折回输入端，
  因此曲线和Mpp纵轴处于同一电压口径；
- HMI触摸和KEY1继续共用`Display_ProcessButtonCommand()`，串口中断只设标志，
  不在中断内发送`sw_period.val`；
- 频谱纵轴只读取队友发布的`components[].amplitude_mv`，显示层不重新做FFT。

## 待实屏确认

1. 用户在淘晶驰编辑器保存最终HMI，并归档到`firmware/HMI/`；
2. 确认512/256曲线ID握手和`addt`长度匹配；
3. 用KEY1切换1T/3T，确认`sw_period`外观和时域us刻度同步；
4. 同步保存信号源、PA0示波器、`adc_b[2048]`、`Upp`和`Mpp`，再决定最终
   峰峰值口径；
5. 不用单张屏幕截图或视觉缩放比例判断幅值是否正确。
