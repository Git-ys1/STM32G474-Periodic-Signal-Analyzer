# V1.6 原生ADC测试集与波形提取验证

## 1. 目的

旧“测试”按钮直接在分析结果层构造波形、峰峰值、有效值和谱峰，只能验证显示，不能验证：

```text
2048点ADC原始码
→ 去除1.65 V偏置
→ 提取一个周期的波形
→ 256点显示快照
→ 794列屏幕重采样
```

V1.6改用Python预生成的原生`uint16_t adc_b[2048]`数据，格式、采样率和电压换算与队友工程一致。测试按钮现在从ADC数组入口经过与真实结果相同的波形提取函数。

## 2. 题目与问答约束

- 第1问：复合信号峰峰值100～250 mV，全部频率分量10～200 kHz。
- 第2问：复合信号峰峰值50～250 mV，全部频率分量10～500 kHz。
- 第3问：第2问信号叠加200 mVpp、频率不低于1 MHz的单频干扰。
- 输入由基波及1个或2个谐波组成，输入无直流偏置。
- 赛区问答明确答复各频率分量之间“没有”相位差，因此测试数据统一采用零相对相位，显示端不测量或显示相位。
- 频谱分量幅值采用正弦表达式中的峰值，单位为mVpk。

STM32 ADC只能采集非负电压，所以生成器在原信号上加入1.65 V ADC中点偏置；桥接层对2048点求均值并去除该偏置。

`phase_fold_gallery.svg`将9组理想波形与相位折叠结果叠加显示，标题中的`T1`～`T9`与测试模式下屏幕“谐波2”末尾的编号一致。

## 4. 第3问的物理边界

1.024 MSPS采样率的奈奎斯特频率为512 kHz。若把不低于1 MHz的200 mVpp干扰直接送入ADC，它会混叠到500 kHz以内，数字显示端无法恢复其原始频率。

因此第3问必须先由ADC前的模拟低通/抗混叠电路抑制干扰。本测试集按40 dB模拟衰减建模：

```text
200 mVpp输入干扰 → 2 mVpp ADC端残余干扰
```

这9组数组验证的是“模拟抑制后的ADC数据→显示”链路，不代替模拟滤波器实测。

## 5. 旧提取方法的问题

旧方法仅使用第一个周期约`Fs/f1`个采样点，再线性拉伸为256点。高频时每周期点数极少：

```text
f1 = 250 kHz
Fs = 1.024 MHz
每周期仅4.096点
```

对于真实基频249.75 kHz、队友500 Hz频率栅格报告为250.0 kHz的第2问
边界场景，离线误差为：

| 方法 | 波形RMSE | 最大点误差 | 峰峰值误差 |
|---|---:|---:|---:|
| 旧：按报告频率截取首周期 | 26.061 mV | 52.768 mV | -32.368 mV |
| 新：频率细化+2048点相位折叠 | 0.865 mV | 3.984 mV | -0.244 mV |

这说明主要误差来自旧的首周期提取，不是显示层插值。

## 6. 新波形提取方法

新算法使用全部2048点：

1. 求ADC码均值并去除1.65 V偏置；
2. 在队友报告基频的±500 Hz范围内，以10 Hz步长搜索相关峰；
3. 从已识别谱线中选取“幅度×谐波次数”最大的谱线作为频率细化参考；
4. 三点抛物线插值后获得仅用于波形折叠的精细基频；
5. 根据精细基频计算每个采样点在一个基波周期内的相位；
6. 将所有周期的采样按相位加权折叠到256个相位槽；
7. 对未覆盖的相位槽做环形线性插值；
8. 再去除微小残余均值，得到一个周期的256点快照；
9. 显示层按1T或3T模式把256点线性重采样到794列。

频率细化只服务于时域波形折叠，不回写或修改队友给出的测量频率。9组
测试中包含多个±250 Hz半频点场景；精细基频最坏误差为1.36 Hz。

9组测试的离线统计：

| 项目 | 最坏值 |
|---|---:|
| 旧首周期方法波形RMSE | 26.061 mV |
| 新频率细化+相位折叠波形RMSE | 0.865 mV |
| 256点到794列显示插值RMSE | 0.749 mV |

在理想量化ADC数据下，当前波形提取与显示插值误差均小于1 mV。

## 7. 已验证与未验证边界

本测试集验证：

```text
原生ADC格式
→ 偏置去除
→ 2048点相位折叠
→ 256点周期快照
→ 1T/3T显示重采样
→ cle/addt与FE/FD握手
→ 波形、频谱和文字显示
```

本测试集不验证：

- 队友ADC硬件采样的模拟误差；
- 队友FFT、Vpp、RMS和谱峰算法的精度；
- 第3问模拟滤波器对1 MHz以上干扰的实际衰减。

测试场景中的Vpp、RMS与谱峰元数据是Python计算的理想期望值，目的在于隔离并验证显示侧链路。
