# 报告插图

本目录保存显示与波形复原模块的可编辑 Visio 图及其导出预览。

| 文件 | 用途 |
|---|---|
| `01_波形复原与显示主流程图.vsdx` | 可编辑的波形复原、Mpp估计与显示主流程图 |
| `01_波形复原与显示主流程图.svg` | 适合插入Word报告的矢量图 |
| `01_波形复原与显示主流程图.png` | 快速预览图 |
| `02_MCU与显示屏交互时序图.vsdx` | 可编辑的MCU与淘晶驰显示屏交互时序图 |
| `02_MCU与显示屏交互时序图.svg` | 适合插入Word报告的矢量图 |
| `02_MCU与显示屏交互时序图.png` | 快速预览图 |
