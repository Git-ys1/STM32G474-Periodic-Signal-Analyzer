# 硬件、接线、屏幕与实体按键基线

## 1. 主控与显示设备

当前主控为 STM32G474VET6 最小系统板。显示设备按采购计划是淘晶驰 X2 系列 7 英寸 800×480 串口屏，型号资料使用 `TJC8048X270_011R`。但商家实际发来的实物是不可触摸版本，因此屏幕仍负责显示和串口接收，现场操作改由板载 KEY1 完成。HMI 上位机模拟器仍可点击虚拟按钮，用于开发和协议调试；不能因为实物不可触摸就删除按钮帧，否则模拟器回归和将来换回触摸屏都会失效。

屏幕当前采用 dashboard 单页面，同时显示上方时域曲线、下方频谱曲线和测量文本。页面尺寸 800×480，两条曲线宽 794、高 145、通道 0。HMI 工程运行时在后初始化事件中发送：

```text
A5 20 01 time_id spec_id 5A
A5 02 07 mode 5A
```

第一帧中的 `time_id` 和 `spec_id` 是 `s_time.id`、`s_spec.id` 的实际数字值；
第二帧同步全局触发下拉框的当前选项。MCU 保存后再发送 `cle` 和 `addt`。
这是当前方案的重要硬件/软件协同接口，不能恢复早期写死 ID 的做法。

## 2. 屏幕接线

```text
STM32 PC10 / USART3_TX  →  淘晶驰 RX
STM32 PC11 / USART3_RX  ←  淘晶驰 TX
STM32 GND               —  淘晶驰 GND
外部 5 V                →  淘晶驰 VCC
```

串口参数：

```text
115200 bit/s
8 data bits
1 stop bit
no parity
no hardware flow control
```

TX 必须接对方 RX，RX 必须接对方 TX，屏幕和 MCU 必须共地。屏幕使用 5 V 供电，STM32 的 USART 是 3.3 V 逻辑。接线前确认所用淘晶驰接口为 TTL，不是 RS232 电平。屏幕背光和控制器电流远大于一个普通 GPIO 的供电能力，必须由系统 5 V 电源单独可靠供电，不能从 STM32 的弱 3.3 V 引脚或细弱飞线取电。

题目要求整机外部单路 5 V 稳压供电。系统内部可以把 5 V 分配给屏幕，并稳压为 MCU/模拟电路所需 3.3 V，但必须关注数字屏幕电流对模拟地、VDDA 和 ADC 参考的干扰。调试幅值误差时，应同时测量 MCU VDDA、屏幕供电和地电位差。

## 3. ADC与采样硬件

当前融合底座使用：

```text
ADC1
PA0 / ADC1_IN1
DMA1 Channel 1
TIM3 TRGO上升沿触发
12位右对齐
2倍过采样，右移1位
6.5 ADC周期采样时间
2048个uint16_t采样点
```

固件使用 `HAL_ADCEx_Calibration_Start(&hadc1, ADC_SINGLE_ENDED)` 做 ADC 自校准，然后启动 TIM3 和 DMA。当前统一采样率常量为 `1024090.0f`，队友 `fft()` 内部仍有 `1024000.0/2048.0` 的频率计算口径，后续做精密标定时必须统一审计。

当前电压换算宏是：

```c
#define ADC_VOLTS_PER_CODE (3.3f / 4096.0f)
```

它假定 VDDA 精确为 3.3 V。用户实测已经表明 ADC 引脚处示波器与屏幕 Vpp 经常相差超过 10 mV，因此必须实测 VDDA 并记录原始 ADC 码、而不是先改屏幕比例。`4096` 与 `4095` 的差别很小，不足以单独解释大误差；采样相位、输入驱动、参考电压和 `Vpp_Robust()` 都要联合排查。

实际模拟前端的完整原理图、运放/滤波器型号、BOM 和增益尚未在当前仓库找到。已有 AD8367 表格属于早期独立测试，不能当作 PA0 当前前端。后续应从信号源 BNC、终端/保护、放大滤波、偏置驱动到 PA0 分段测量，并向队友取得原理图或清晰实物资料。

## 4. KEY1硬件与操作

最小系统板非复位按键 KEY1 连接：

```text
PB8 / BOOT0，芯片第95脚
松开：R6 10 kΩ下拉至GND，低电平
按下：接通3.3 V，高电平
有效电平：高
中断：上升沿EXTI
```

当前 `main.c` 提供宏开关：

```c
#define BOARD_KEY_CONTROL_ENABLE 1U
#define BOARD_KEY_DEBOUNCE_MS    30U
#define BOARD_KEY_LONG_PRESS_MS  1000U
```

EXTI 中断回调只记录按下时刻和活动标志，不在中断里等待松开，也不调用 UART 或曲线绘制。主循环 `BoardKey_Task()` 观察 PB8 回到低电平后计算持续时间：

```text
小于30 ms：忽略为抖动
30～999 ms：Display_TogglePeriods()
至少1000 ms：Display_RequestRefresh()
```

因此当前权威行为是：短按在 1T/3T 之间切换，长按执行原“刷新”命令，退出测试覆盖并恢复真实 ADC 自动刷新。某些旧文档曾写长按“测试”，属于文档漂移；以当前 `main.c` 和已经验收的实机行为为准。若后续希望改成长按测试，必须作为新需求明确修改，不能在交接时偷偷替换。

实体按键和 HMI 按钮共用 `Display_ProcessButtonCommand()`，这是稳定性关键。过去单独写一套 KEY 显示逻辑会造成刷新后立刻被自动状态覆盖、画面闪一下又恢复。当前只把 KEY 映射为已有命令，确保两种输入拥有同一状态转换。

## 5. HMI工程与控件

当前源工程主要在资料目录：

```text
F:\AcademicHub\000资料相关\电赛\2026TI杯
\淘晶驰串口屏\testv2.HMI
```

仓库有配套归档：

```text
projects\tjc_display_demo\HMI
\TJC8048X270_dashboard_v1.3.1.HMI
```

页面名 `dashboard`。曲线：

```text
s_time  时域
s_spec  频谱
```

按钮命令：

```text
1T    A5 01 01 5A
刷新  A5 01 02 5A
3T    A5 01 03 5A
测试  A5 01 04 5A
清除  A5 01 05 5A
停止  A5 01 06 5A
触发方式下拉框  A5 02 07 mode 5A
```

前六项按钮不勾选“发送键值”，避免一次点击同时产生自定义帧和标准 `0x65`
帧。V2.0触发下拉框的`path`依次为`无触发、上升过零、下降过零、正峰值`，
弹起事件在`down==0`时用`prints cb0.val,1`发送`mode=0～3`；完整帧依次为
`A5 02 07 00 5A`至`A5 02 07 03 5A`。固件与HMI默认均设为上升过零
（`mode/val=1`）。`cb0.vscope`设为全局，页面后初始化在曲线ID帧之后再发送
当前触发帧，避免刷新页面后显示选择与MCU状态不一致；它只改变时域周期的显示
起点，不改变测量结果。文本控件为
`t_vpp、t_rms、t_freq、t_c1、t_c2、t_c3`，HMI 与 C 源码统一 UTF-8。
newlib-nano 未链接 `_printf_float`，所以显示代码使用整数定点格式化，不能随便
改回 `%.1f` 后又发现数字为空。

## 6. 现场验收边界

HMI 模拟器看到按钮帧，只能证明 HMI 事件发出了；串口设备窗口看到 MCU 命令和 FE/FD，才能证明双向链路；实物屏显示正确，才能证明 HMI 资源与固件匹配；示波器/原始 ADC/屏幕数值一致，才能证明测量链正确。四种证据不能混为一谈。烧录前后都应保存 HEX 时间和哈希，避免用户实际运行的仍是旧固件。
