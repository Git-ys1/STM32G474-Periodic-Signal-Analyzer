# 当前软件架构、数据流与绘图原理

## 1. 总体架构

当前不是“所有逻辑都在 display 里”，也不是显示模块自行做完整 FFT。软件由三层组成：

```text
队友采集与测量层
→ 用户AnalyzerBridge桥接与波形重建层
→ 用户Display/HMI显示与交互层
```

权威工程的初始化顺序是：

```c
MX_GPIO_Init();
MX_DMA_Init();
MX_DAC1_Init();
MX_USART3_UART_Init();
MX_TIM3_Init();
MX_ADC1_Init();

HAL_ADCEx_Calibration_Start(&hadc1, ADC_SINGLE_ENDED);
HAL_TIM_Base_Start(&htim3);
HAL_ADC_Start_DMA(&hadc1, (uint32_t *)adc_b, 2048);
AnalyzerBridge_Init();
Display_Init(&huart3);
```

主循环等待 `AdcConvEnd`，完成一次分析并发布快照，然后执行 `BoardKey_Task()` 和 `Display_Task()`。ADC DMA 完成回调设置标志并停止 DMA，主循环分析完成后重新启动。

## 2. 队友测量链

`adc_b[2048]` 是 ADC1 原始 12 位码。主循环把每个码换成电压：

```text
input[2i] = adc_b[i] × 3.3 / 4096
VO[i]     = input[2i]
input[2i+1] = 0
```

随后调用队友 `fft()`。它使用 `arm_cfft_f32` 和 `arm_cmplx_mag_f32`，依次找三组最大剩余谱峰；每找到一峰，就将该位置左右各 8 个频点的平方和开方并换算成峰值幅度，再把该频带清零。第一次 FFT 的 `F/V、FB/VB、FC/VC、flag` 必须立刻复制到局部数组，因为 `Vpp_R()` 内部还会调用 FFT 并覆盖全局结果。

Vpp 使用 `Vpp_Robust(VO,2048)`：复制并排序 2048 点，以低端若干点均值和高端若干点均值之差作为峰峰值。RMS 来自 `Vpp_R()` 的整数周期计算。Goertzel 对三路频率都执行，但当前结果被 `(void)` 丢弃，尚未替换显示口径。显示中的频谱数值仍来自第一次 FFT 快照。

当前算法的重要已知行为是：至少会寻找两峰；只有第三峰幅值低于约 4 mV 才把 `flag` 设为 2。因此纯正弦也可能出现第二个“谐波”。它不是 `display.c` 生成的，而是队友峰值判定缺少“第二峰可以不存在”的阈值和整数倍验证。

## 3. AnalyzerBridge桥接

`AnalyzerBridge_PublishReal()` 接收原始 ADC 和队友测量元数据，建立静态 `AnalyzerResult`。它完成：

1. V 转 mV；
2. 根据 `flag` 复制最多三个分量；
3. 按频率升序排序；
4. 将最低有效频率作为对外基频；
5. 保存 Vpp、RMS、频率和幅值；
6. 从完整 `adc_b[2048]` 构建一个周期的 256 点显示波形；
7. 增加 sequence，原子式替换最新真实快照；
8. 测试覆盖模式下仍继续保存真实结果，刷新时可以立即恢复。

波形重建不是“根据三个幅值画三个正弦”。因为队友没有提供每个分量的相位，单靠频率和幅值无法唯一决定复合波形。当前使用等效相位折叠：

```text
计算adc_b均值并去直流
→ 在队友粗基频±500 Hz内以10 Hz搜索相关峰
→ 选信息量较强的谱线作为参考
→ 三点抛物线细化折叠频率
→ 对2048个样点计算基频相位
→ 每点按线性权重投入相邻两个256相位槽
→ 每槽加权平均
→ 空槽在环形相邻有效槽间线性插值
→ 对256槽再去均值
```

该方法利用多个周期采样覆盖不同相位，因此高频时不只取第一个周期的 4～10 个点。但若输入频率与采样率形成精确低分母有理比，例如约 `Fs/4`，无论采多少周期都只有四个真实相位；256 个槽中的其他点都是插值，不能创造真实信息。PC 离线工具已经验证精确 256 kHz 的线性折叠误差明显，而知道正确频率和谐波模型的最小二乘拟合能大幅改善。正式优化仍需考虑频率误差、伪峰和残差，不能只按频段选择槽数。

V2.1.0在普通折叠之后增加可选Huber第二遍：先由普通256槽波形预测每个
原始样点的周期值，再对残差取中位数和MAD，以
`delta=max(1.345*1.4826*MAD, 1.5 ADC_LSB)`计算Huber权重，最后将原始
2048点按该权重重新折入同一批槽。状态开关关闭时完全沿用上述普通折叠；
开启时只替换`waveform_mv`，不改Vpp、RMS、频率和频谱元数据。它用于抑制
少量异常样点，不解决低相位覆盖、错误基频或连续污染。

## 4. Display显示链

`Display_Task()` 只消费 `AnalyzerResult`。时域：

```text
256点waveform_mv
→ 根据1T或3T选择源位置
→ 线性插值到794个横向点
→ 根据自动纵向满量程映射到0～144
→ 对发送缓冲做淘晶驰水平反向补偿
→ cle time_id,0
→ addt time_id,0,794
```

1T/3T 不是改动真实波形，而是改变 `source_position` 在一个屏宽内遍历一周期还是三周期。当前使用普通线性插值；三次样条可能在谐波尖锐处过冲，且不能补回没有采到的相位，所以不是默认改进方向。

频谱：

```text
components[0..2]
→ 0～500 kHz映射到带左右边距的794点横轴
→ 幅值相对本帧最大分量映射到0～144
→ 每个有效分量形成一根竖直线谱
→ 淘晶驰方向补偿
→ cle spec_id,0
→ addt spec_id,0,794
```

频谱图是定性线谱，准确数值由下方文本显示。横向使用 `DISPLAY_SPEC_X_MARGIN=32`，避免 0 Hz 和 500 kHz 贴在边缘。时域和频谱必须分别使用 dashboard 上报的真实曲线 ID。

文本显示从 `AnalyzerResult` 直接格式化：

```text
t_vpp  Upp
t_rms  Urms
t_freq f1
t_c1   基波频率/峰值
t_c2   谐波1频率/峰值
t_c3   谐波2频率/峰值
```

显示代码不重新计算这些测量值。由于 Keil 使用 newlib-nano 且未启用 `_printf_float`，代码先把浮点数四舍五入成放大 10 或 100 倍的无符号整数，再拼出小数文本。

## 5. HMI协议与状态机

普通 TJC 指令以 `FF FF FF` 结束。页面初始化连续发送曲线ID帧、触发同步
帧和折叠方式同步帧：

```text
A5 20 01 time_id spec_id 5A
A5 02 07 mode 5A
A5 02 08 enabled 5A
```

按钮发送：

```text
A5 01 command 5A
```

命令 `01/02/03/04/05/06` 分别对应 1T、刷新真实、3T、测试自动、清除、停止。
触发方式下拉框发送五字节带参数帧`A5 02 07 mode 5A`，`mode=0/1/2/3`
分别选择无触发、上升过零、下降过零和正峰值。刷新和测试进入 3 秒自动刷新
模式；停止冻结画面；清除只清内容，不必改变运行模式。上电默认停止，页面
握手本身不强制开始绘制。

折叠方式状态开关发送`A5 02 08 enabled 5A`：`enabled=0`为普通折叠，
`enabled=1`为Huber折叠，默认0。串口接收中断只记录请求，真正的重建和
重绘在`Display_Task()`主循环完成；真实模式用当前最新一帧ADC重建，测试
模式用当前测试组重建。

曲线发送保持：

```text
cle id,0
addt id,0,794
等待 FE FF FF FF
发送794字节
等待 FD FF FF FF
```

USART3 通过 `HAL_UART_Receive_IT` 每次接收一个字节。回调只解析帧和设置待处理动作，阻塞式绘图在主循环中执行。错误回调清 ORE、flush、丢弃残帧并重新挂接接收。这样避免 2048 点 FFT 和排序期间主循环来不及轮询串口。

## 6. 当前刷新和相位问题

真实/测试运行模式每 3 秒安排一次 `UI_ACTION_DRAW_DASHBOARD`。停止只禁止后续
调度；若某次绘制动作已经开始，停止不能中途撤销 UART 透传，但通常影响不大。
帧间波形横移来自桥接层每帧把 `adc_b[0]` 定义为相位零点，即
`phase_cycles=0`，而外部信号与 ADC 时钟不同步。

V2.0在显示层加入确定相位锚：默认从主正峰向前寻找上升过零点，也可选择下降
过零、正峰值或关闭触发。过零点使用线性亚槽插值并检查2%峰峰值滞回带，正峰
使用三点抛物线细化。显示层只把256槽周期波形做循环旋转，仍保留淘晶驰水平
反向补偿；它不改 Vpp、RMS、频率和频谱幅值。该实现已离线和编译验证，仍需
实机连续20帧及2/3/5秒刷新间隔验收。

## 7. 测试模式边界

测试按钮可使用 Python 预生成的原生 `uint16_t[2048]` 数组，走同一个波形折叠与绘图链；但 Vpp、RMS 和频谱元数据使用测试用例预期值，因此它验证的是显示、协议和重建，不验证队友真实 FFT/Vpp。正式比赛可通过宏关闭测试模式。以后看到漂亮的测试波形，不能据此宣称 ADC 测量已通过。
