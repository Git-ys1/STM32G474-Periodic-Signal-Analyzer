# V1.9.0队友ADC1底座融合发布说明

发布日期：2026-07-31

## 1. 融合原则

本版明确以`projects/teammate_adc_reallynewest!`为采集与分析底座，不把队友改动零散猜测式搬入显示工程。实施顺序为：

1. 独立归档并提交队友原始快照；
2. 将其CubeMX生成的ADC、DMA、GPIO、IRQ和`.ioc`文件同步到融合工程；
3. 保留融合工程已经验证的Keil、CMSIS-DSP、桥接、显示和KEY1叠加层；
4. 在队友一次分析完成的位置发布统一`AnalyzerResult`。

原始快照提交为`44fc481`，因此后续可审计“队友原始代码”和“融合叠加代码”的差异。

原始`.ioc`的实际外设配置已经是ADC1，但`ProjectManager.functionlistsort`仍残留
`MX_ADC2_Init-ADC2`。融合工程仅将该元数据修正为`MX_ADC1_Init-ADC1`，
防止以后打开CubeMX重新生成时恢复错误的初始化名称；原始快照保持不动。

## 2. 队友最新版变化

| 项目 | 上一底座 | 本版底座 |
|---|---|---|
| ADC | ADC2，PA7/IN4 | ADC1，PA0/IN1 |
| DMA | DMA1 Channel 2 | DMA1 Channel 1 |
| ADC过采样 | 无本版配置 | 2倍，右移1位 |
| FFT幅值 | 单个最大频点 | 峰值附近±8频点RSS |
| Vpp鲁棒统计 | 5个极值均值 | 排除端点后各10点均值 |
| RMS周期取整 | `floor()` | `round()` |
| 精测源码 | 无 | `goertzel_sync.c/.h` |

队友`main.c`会计算三路Goertzel结果，但原始版尚未使用这些结果。本融合版原样保留计算，暂不擅自改变正式显示幅值。

## 3. 我们叠加的内容

- `analyzer_bridge.c/.h`：接收一次完整分析结果并生成稳定快照；
- `display.c/.h`：dashboard、曲线、文本、UART协议和按钮状态机；
- USART3：PC10/TX、PC11/RX、115200、8N1；
- KEY1：PB8高电平有效，上升沿记录按下，主循环判定松开时长；
- 短按：调用原1T/3T命令；
- 长按：调用原刷新命令，退出测试锁存并恢复真实ADC显示。

## 4. 真实数据路径

```text
TIM3 TRGO
→ ADC1 PA0/IN1
→ DMA1 Channel 1
→ adc_b[2048]
→ 转换为VO[2048]
→ 队友fft()
→ 立即保存F/V、FB/VB、FC/VC和flag
→ Vpp_Robust()
→ 三路goertzel_sync()保留结果
→ Vpp_R()
→ AnalyzerBridge_PublishReal(adc_b, ...)
→ 相关搜索细化折叠频率
→ 所有2048个实采点按相位投入256槽
→ 环形填补未覆盖槽并去直流
→ Display_Task()
→ 淘晶驰dashboard
```

时域图不是根据频率和幅值合成出来的，也不是截取第一个周期后拉伸；它来自当前真实ADC帧的2048个采样点。

## 5. 历史问题交叉核对

| 历史问题 | 本版处理 |
|---|---|
| `Vpp_R()`再次FFT覆盖谱峰 | 第一次FFT后立即快照 |
| 大型结果对象压坏1 KB主栈 | 桥接和显示大对象保持模块静态 |
| ArmClang启动进入半主机BKPT | 保留`__ARM_use_no_argv` |
| FFT期间UART轮询导致ORE | 保留USART3单字节中断接收 |
| 实体键与触摸键维护两套逻辑 | 全部汇入同一按钮命令入口 |
| 页面曲线ID硬编码错误 | 继续由dashboard初始化帧动态上报 |
| `addt`未等待屏幕准备 | 保留FE/FD完整握手 |
| 时域左右镜像 | 保留时域发送方向补偿 |
| 队友工程含个人绝对DSP路径 | 融合工程使用仓库相对路径 |
| 旧首周期拉伸失真 | 继续使用完整缓冲区256槽相位折叠 |

## 6. 采样率口径

TIM3当前配置对应约1,024,096 Hz。为了与队友最新版Goertzel口径一致，本版桥接和Goertzel使用：

```c
#define ANALYZER_SAMPLE_RATE_HZ 1024090.0f
```

队友FFT内部仍保留原`1024000.0f`频率换算，本轮不擅自重写其算法。实际信号联调时应以仪器标定决定最终统一值。

## 8. 冻结结论

V1.9.0已经完成“队友ADC1底座 + 我们显示叠加层”的结构融合，编译、烧录和后台运行链路成立。下一轮直接进行真实ADC信号源联调，不再重新搬运或重构主链。
