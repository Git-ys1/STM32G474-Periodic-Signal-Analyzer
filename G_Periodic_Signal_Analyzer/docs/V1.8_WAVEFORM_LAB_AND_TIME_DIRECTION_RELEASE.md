日期：2026-07-31

## 发布内容

本版冻结以下三项阶段成果：

1. 修复淘晶驰时域曲线整周期左右镜像；

## 时域方向故障

### 现象

同一组T102波形在PC实验室中相位0后先上升，在屏幕中却先下降，峰谷位置满足
`x → 1-x`。

### 根因

淘晶驰`addt`整帧曲线的横向写入方向与显示算法逻辑横坐标相反。频谱路径已有
补偿，时域路径遗漏，因此整个周期被水平镜像。该问题与纵坐标原点在左上角无关。

### 修复

`Display_DrawTimeResult()`在写入发送缓冲时反转横坐标：

```c
s_curve_buffer[(DISPLAY_CURVE_WIDTH - 1U) - i] = mapped_value;
```

只改变发送顺序，不改变ADC数据、幅值映射、相位折叠、1T/3T、频谱和HMI协议。

## 波形实验室

入口：

```powershell
python tools\custom_waveform_lab.py
```

支持：

- 基波加0至2个整数次谐波；
- 1.024 MSPS、2048点、12位ADC量化；
- 64、128、256相位槽比较；
- 相位折叠与794列屏幕重建；
- 已知谐波阶次的`sin/cos`最小二乘拟合；
- 2048点ADC码及STM32头文件导出；
- 均匀频率网格、精确有理共振和共振邻域混合扫描。

三张图分别展示完整采集窗、一个周期的多方法重建对比，以及每个相位槽实际获得
的采样证据。详细说明见[自定义周期波形实验室](CUSTOM_WAVEFORM_LAB.md)。

## 精确256 kHz结论

在`Fs=1.024 MHz`时，精确256 kHz对应`f/Fs=1/4`，2048点无论采多长都只重复
4个真实相位：

| 方法 | 显示RMSE |
|---|---:|
| 64槽相位折叠 | 8.375 mV |
| 128槽相位折叠 | 8.222 mV |
| 256槽相位折叠 | 8.191 mV |
| 谐波最小二乘 | 0.236 mV |

降低槽数不能增加真实相位。谐波最小二乘能恢复，是因为题目限制了分量数量和整数
谐波结构，而不是因为4个相位足以恢复任意周期波形。

## 频率误估风险

若真实信号仍是精确256 kHz，但算法误用256.1 kHz计算相位：

- 计算硬覆盖率虚高到82.03%；
- 相位折叠显示RMSE恶化到27.33 mV；
- 谐波最小二乘样本残差升到13.80 mV。

因此后续自适应策略不能只看由估计频率推导的覆盖率，还必须结合频率跨帧稳定性、
样本拟合残差、矩阵秩和条件数。当前结论只进入PC离线实验室，尚未替换正式固件
波形算法。
