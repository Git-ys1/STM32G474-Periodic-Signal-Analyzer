# 当前问题与下一步

## P0：双ADC真实输入验收

1. 将同一低阻、共地、0至VDDA范围内的信号同时送入PA0和PA1；
2. 同步记录信号源设置、PA0示波器、PA1示波器和VDDA；
3. 在两路DMA完成后导出`adc_b[2048]`、`adc_b1[2048]`和`VO[4096]`；
4. 核对交错顺序、双ADC增益/偏置失配和相邻点跳变；
5. 同帧记录屏幕Upp、Mpp、Urms、基频和频谱。

没有上述同帧证据，不得通过修改显示缩放“校准”Upp。

## P1：4096-2测量口径

- FFT频响校正已改为先修正幅值数组，必须用10至500 kHz实测分段边界；
- FFT频率常量仍有2048000近似值，桥接/Goertzel使用2048193，最终以实测
  TIM3触发率统一；
- 队友旧`Vpp_Robust()`本轮不优化，等待新函数；
- Goertzel尚未与新的FFT频响校正做同口径标定；
- 纯正弦伪第二峰仍需绝对阈值、相对阈值、噪声底和整数倍关系审计。

## P2：显示与材料

- 用户保存最终HMI源文件到`firmware/HMI/`；
- 实屏确认1T/3T、触发、Huber、512点时域和256点频谱；
- 报告只描述代码链路和设计思路，最终竞赛叙述交给网页端整合；
- V1.x至V2.4历史验证不重写，只在入口标明当前V2.5口径。
