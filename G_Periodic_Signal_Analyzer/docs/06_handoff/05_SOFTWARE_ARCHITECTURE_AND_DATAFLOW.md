# 软件架构与数据流

## 采集层

ADC1在TIM3 CH4上升沿采PA0，ADC2在下降沿采PA1，两路DMA各写入2048个
`uint16_t`。队友主循环按时间顺序交错并换算：

```c
VO[2*i]   = adc_b[i]  * 3.3 / 4096.0;
VO[2*i+1] = adc_b1[i] * 3.3 / 4096.0;
```

得到约2.048193 MS/s的`VO[4096]`。同一被测信号必须同时送入PA0和PA1。

## 队友测量层

`VO`复制到复数FFT输入后执行4096点FFT。`4096-2`先对前1024个幅值点按频率
区间除以前端标定系数，再搜索2至3条谱峰。第一次FFT后必须立即保存三路频率
和幅值，因为`Vpp_R()`会再次FFT并覆盖全局结果。

`Vpp_Robust(VO,4096)`和`Vpp_R()`继续属于队友口径，本轮未修改。Goertzel
结果仍只计算不显示。

## 桥接层

桥接采用两阶段提交：

1. `AnalyzerBridge_PrepareReal()`在`Vpp_R()`之前同步读取完整VO和频谱快照；
2. 4096点VO用于相关频率细化、256槽相位折叠、Huber第二遍、已识别谐波
   投影和全样本模型Mpp；
3. `Vpp_R()`完成后，`AnalyzerBridge_PublishPreparedReal()`写入Vpp/RMS、
   序号和有效标志，并原子更新真实结果快照。

桥接不再读取原始ADC码、不再做`3.3/4096`，也不缓存4096点真实输入副本。
真实折叠模式变化在下一帧生效；测试数组只在测试入口换算一次。

## 显示层

`Display_Task()`读取稳定`AnalyzerResult`：

- 256点周期模型按1T/3T映射为512点时域曲线；
- 最多3条频谱分量映射为256点频谱；
- 更新Upp、Mpp、Urms、基频与谐波文本；
- 通过`cle/addt`和FE/FD握手发送曲线；
- USART3中断只收字节、解析帧和登记动作，阻塞绘图留在主循环。

页面初始化帧仍为`A5 20 01 time_id spec_id 5A`，曲线ID不得硬编码。
