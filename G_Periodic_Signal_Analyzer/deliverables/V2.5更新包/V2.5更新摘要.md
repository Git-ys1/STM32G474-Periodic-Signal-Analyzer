# V2.5更新摘要

适用基线：你最新发来的`4096-2`工程，并且已经保留此前融合好的显示代码。

## 一、可以直接覆盖的文件

只覆盖下面两个桥接层文件：

| 文件 | 操作 |
|---|---|
| `Core/Inc/analyzer_bridge.h` | 直接覆盖 |
| `Core/Src/analyzer_bridge.c` | 直接覆盖 |

`display.c/.h`这次没有变化，不需要替换。包内故意不放`main.c`，不能用我们的
`main.c`覆盖你的采集、FFT、Vpp、RMS或按键逻辑。

## 二、main.c必须手工改两处

### 修改1：统一桥接采样率，并删除桥接层旧码值换算宏

找到：

```c
#define ANALYZER_SAMPLE_RATE_HZ  1024090.0f
#define ADC_VOLTS_PER_CODE       (3.3f / 4096.0f/6.33)
```

改成：

```c
#define ANALYZER_SAMPLE_RATE_HZ  2048193.0f
```

说明：你原来生成`VO[4096]`的代码保持不动；删掉的只是桥接层重复使用的
`ADC_VOLTS_PER_CODE`。

### 修改2：桥接先读取未被Vpp_R()改写的VO，再发布Vpp/RMS

找到从Goertzel到旧`AnalyzerBridge_PublishReal()`结束的代码：

```c
GoertzelResult r=goertzel_sync(VO,4096,2048193,F),rB=goertzel_sync(VO,4096,2048193,FB),rC=goertzel_sync(VO,4096,2048193,FC);
float Vrms=Vpp_R();

AnalyzerBridge_PublishReal(
        adc_b,
        ADC_SIZE,
        ADC_VOLTS_PER_CODE,
        ANALYZER_SAMPLE_RATE_HZ,
        vpp,
        Vrms,
        spectrum_flag,
        spectrum_frequencies_hz,
        spectrum_amplitudes_v
);
```

整段替换为：

```c
GoertzelResult r=goertzel_sync(VO,4096,ANALYZER_SAMPLE_RATE_HZ,F),rB=goertzel_sync(VO,4096,ANALYZER_SAMPLE_RATE_HZ,FB),rC=goertzel_sync(VO,4096,ANALYZER_SAMPLE_RATE_HZ,FC);

AnalyzerBridge_PrepareReal(
        VO,
        ADC_SIZE,
        ANALYZER_SAMPLE_RATE_HZ,
        spectrum_flag,
        spectrum_frequencies_hz,
        spectrum_amplitudes_v
);

float Vrms=Vpp_R();
AnalyzerBridge_PublishPreparedReal(vpp, Vrms);
```

必须把`AnalyzerBridge_PrepareReal()`放在`Vpp_R()`之前，因为队友当前
`Vpp_R()`会原地去直流并清零`VO`尾部；桥接必须先消费完整的浮点`VO[4096]`。

### 修改3：消除Arm Compiler 6.7条件优先级警告

找到：

```c
if(VC<0.00477 || FC<FB && FC<F)
```

改成：

```c
if(VC<0.00477 || (FC<FB && FC<F))
```

只补括号，不改变原判断逻辑。

## 三、本次实际变化

- 真实显示波形、频率细化、Huber折叠和模型Mpp直接读取队友已经换算好的
  `VO[4096]`浮点电压。
- 桥接层不再读取`adc_b`，不再自己做`3.3/4096`，也不存在把2048点
  `adc_b`误当4096点读取的越界。
- 采用“Prepare VO → 队友Vpp_R() → Publish Vpp/RMS”两阶段提交，显示层只会
  读取完整结果。
- 已同步`4096-2`中FFT频响校正的新位置；队友的`Vpp_Robust()`没有修改。
- 队友生产版随机测试保持关闭；KEY1长按继续刷新真实ADC。

完成上述两处手工修改后Clean Rebuild。本包已按同样步骤用Arm Compiler 6.7
验证：`0 Error(s), 0 Warning(s)`。
